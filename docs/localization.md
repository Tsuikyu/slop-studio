# Localization 0.7

Supported packs: en-US, de-DE, ja-JP, ko-KR. UiText localizes common controls, canvas labels, command names, startup/About and four self-contained HTML manuals. User-approved authored translations were used after DeepL Pro was unavailable. Some dynamic/vendor error text remains in the original language. Text input and persisted device/command values remain semantic values; display localization does not rewrite them.
