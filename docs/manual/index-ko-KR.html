Studio 0.9: 믹서와 트랙 스택

내장 이펙트와 VST3/CLAP 이펙트가 같은 인서트 목록에 표시됩니다. 왼쪽 클릭은 편집, 오른쪽 클릭은 바이패스 또는 제거이며, 같은 채널 안에서 드래그하여 순서를 바꿀 수 있습니다. 센드 +로 포스트 페이더 Aux 전송을 설정합니다. EDM Ducker는 트랙 신호를 오디오 트리거로 사용할 수 있지만 외부 플러그인의 사이드체인 입력은 지원하지 않습니다.

Shift로 트랙 헤더를 여러 개 선택하고 오른쪽 클릭 메뉴에서 폴더 또는 서밍 스택을 만듭니다. 서밍 스택은 자식 오디오를 부모 믹서 채널로 보냅니다. 화살표로 자식을 접거나 펼칩니다. 중첩 스택은 지원하지 않습니다.

같은 트랙의 여러 리전을 선택한 뒤 Ctrl+J 또는 메뉴로 합칩니다. 오디오는 새 WAV로 만들어지며 원본 파일은 유지됩니다. Launcher 또는 컴핑에서 사용하는 리전은 합칠 수 없습니다. 눈금자 위쪽을 드래그해 반복 범위를 만들고 양 끝을 드래그해 조정합니다. 피아노 롤에서는 Shift+휠로 가로 이동합니다.

Sampler는 오디오 가져오기, 사용 가능한 입력 녹음, 루트 음과 ADSR 조절을 지원합니다. 지연 보정은 스택과 Aux 오디오 경로를 고려하지만 외부 사이드체인과 모든 플러그인 구성은 검증되지 않았습니다.

Studio 0.8: 선택, MIDI 및 글로벌 트랙

포인터 도구로 노트 주위를 드래그하면 영역을 선택합니다. Shift 클릭은 선택을 추가하거나 해제하고 Alt 드래그는 선택한 노트를 복제합니다. 빈 곳을 더블 클릭하거나 연필 도구를 켜면 노트를 만듭니다. Ctrl 도구는 영역 선택, 연필, 지우개 중에서 고릅니다. Ctrl+A/C/X/V는 마우스 아래 편집기에 적용되며, 그 밖에서는 포커스된 편집기를 사용합니다. 붙여넣기 위치는 재생 헤드입니다. 방향키로 노트를 이동하고 Shift+위/아래로 옥타브를 바꿉니다. Ctrl+위/아래는 세로, Ctrl+좌/우는 가로 확대/축소입니다. Z는 선택 영역 또는 전체 내용에 맞추고 다시 누르면 이전 보기로 돌아갑니다. Shift+I는 선택을 반전합니다.

Ctrl+휠은 편집기를 확대/축소하고 Shift+휠은 가로로 스크롤합니다. Ctrl+Alt+휠은 작업 공간 전체 배율을 바꿉니다. 환경 설정 → 표시에서 마우스, 트랙패드, 터치스크린, XInput 또는 DirectInput 컨트롤러를 선택합니다. 터치스크린 모드는 두 손가락 이동과 핀치 확대/축소를 처리합니다. tablet 인터페이스 전체를 재현한 것은 아닙니다. 실제 태블릿과 모니터 간 DPI 변경은 검증하지 않았습니다.

선택한 소프트웨어 악기는 녹음 대기 없이 MIDI를 받습니다. 노트 녹음에는 트랙 녹음 대기를 켜세요. 보기 → MIDI 입력 모니터에서 장치, 수신 수, MIDI 메시지를 확인할 수 있습니다. 키보드에 포트가 여러 개라면 보조 제어 포트가 아닌 노트 출력 포트를 선택하세요. 실제 Keystation 49 입력 포트를 여는 데 성공했지만 물리적인 건반 연주는 확인하지 않았습니다.

녹색 Sampler 슬롯을 왼쪽 클릭하면 PCM 파형, 루트 음 매핑 및 연주 키보드를 엽니다. 오른쪽 클릭하면 Sampler 프리셋이나 설치된 VST3/CLAP 악기로 교체합니다. 내장 뱅크는 독자적으로 생성한 PCM 멀티샘플이며 the vendor 샘플을 사용하지 않습니다. EXS 라이브러리나 reference application Sampler의 전체 변조 시스템은 지원하지 않습니다.

G를 누르거나 편곡 영역 맨 위의 가는 경계를 아래로 드래그하면 글로벌 트랙을 표시합니다. 더블 클릭하여 템포, 박자표, 코드 진행을 편집합니다. Am | Fmaj7 | C | G처럼 |로 코드를 구분하세요. “코드 MIDI 트랙 만들기”를 선택하면 편집 및 재생 가능한 노트를 생성합니다. Session Player나 가변 템포 오토메이션의 완전한 구현은 아닙니다. 컴핑에서는 오디오 및 MIDI 테이크의 영역을 선택할 수 있습니다.

가져오기, 동영상 및 예제

파일 열기와 프로젝트 가져오기는 .slopdaw, .mid, .midi, .flp, .als, .dawproject를 처리합니다. MIDI 드롭은 트랙 또는 리전을 추가하고 프로젝트로 열면 템포와 박자표도 가져옵니다. FLP/ALS는 일부 기능만 변환합니다. 가져온 노트는 Sampler로 들어볼 수 있으나 원래 장치, 프리셋, 워프 및 전체 라우팅을 복원한 것은 아닙니다. 보기 → 가져오기 보고서에서 변환 경고를 확인하세요. 모든 FLP/ALS 호환성을 보장하지 않습니다.

동영상 가져오기는 MP4/MOV 등 FFmpeg가 해독하는 형식을 읽고 외부 파일 참조를 저장하며, 오디오가 있으면 추출하고 재생 헤드에 연결된 미리보기를 엽니다. FFmpeg는 PATH, SlopStudio.exe 옆 또는 SLOPX_FFMPEG 환경 변수로 지정하며 이 배포본에는 포함하지 않습니다. 미리보기는 약 165 ms 간격의 비동기 프레임 디코딩을 사용하는 위치 정렬 도구이며, 전체 프레임 속도의 영상 편집기는 아닙니다. 프로젝트 저장 시 외부 영상을 자동 수집하지 않습니다.

빠른 시작에 EDM Sample - Melodic House가 포함됩니다. 8트랙, 64마디의 독자적인 예제로 Sampler, MIDI, 코드, Launcher 셀, 오토메이션 및 내장 효과를 사용합니다. 외부 악기 플러그인은 필요하지 않습니다.

내장 효과는 회전 노브와 전달 곡선/엔벨로프 표시를 제공합니다. 곡선은 파라미터를 반영하고 미터는 실제 DSP 값을 읽습니다. 도움말 → MIT 라이선스는 배포된 MIT 법률 원문 전체를 그대로 표시합니다. “부드러운 UI 애니메이션”은 표시 갱신 간격을 줄이며 오디오 처리를 바꾸지 않습니다.

오디오 복구 및 검증 범위

ASIO 시작 신호와 버퍼 응답을 별도 IPC 이벤트로 분리했습니다. 동일 샘플레이트 알림과 재동기화 요청은 재생을 중단시키지 않습니다. 드라이버 프로세스가 종료되거나 버퍼가 멈추면 오류를 알리고 재생 버튼으로 다시 연결합니다. 실제 FL Studio ASIO로 연속 재생, 팬 변경, 탐색 및 재시작을 검증했습니다. 모든 드라이버나 장치 초기화 중 끊김 없는 오디오를 보장하지 않습니다. WASAPI 공유 모드는 검증했지만 독점 모드는 엔드포인트에 따라 다릅니다.

프로젝트를 만들고 오디오를 설정한 다음 소재를 추가해 편곡하고 믹싱하세요. 이 설명서는 현재 빌드의 기능을 다루며 the referenced application와의 완전한 호환성을 뜻하지 않습니다.

시작하기

앱 폴더 전체를 압축 해제하고 SlopStudio.exe를 실행하세요. 빠른 시작에서 빈 프로젝트, 실제로 소리가 나는 Slop Launcher 스타터, First Light 예제, 장치 설정을 열 수 있습니다. 작업은 .slopdaw 프로젝트로 저장합니다.

화면 이동과 크기 변경

Ctrl+휠은 포인터 아래의 편곡 화면이나 피아노 롤만 확대/축소하며 포인터의 음악적 위치를 유지합니다. Shift+휠은 가로 이동, 일반 휠은 세로 이동입니다. Ctrl+Alt+휠은 전체 작업 영역 배율을 1%씩 바꿉니다. 재생 헤드나 눈금자를 드래그해 이동할 수 있으며 가장자리에서는 화면이 스크롤됩니다. 패널 경계는 8픽셀 너비로 잡을 수 있습니다.

재생과 녹음

Space는 재생/정지, 숫자 키패드 0은 정지, Return은 정지 후 처음으로 이동입니다. R은 녹음 대기 중인 트랙에 녹음합니다. 오디오는 녹음 → 입력 라우팅 / 모니터링에서 입력을 할당하고 대상 트랙을 녹음 대기 상태로 설정하세요. 사용 가능한 실제 입력이 필요합니다. 정지하면 WAV 파일을 완성하고 리전을 만듭니다. Ctrl+K는 실제 건반 없이 MIDI를 연주·녹음할 수 있는 음악 입력 키보드를 엽니다.

오디오 설정

Windows 공유 오디오는 WASAPI를 선택합니다. 설치된 64비트 ASIO 드라이버도 사용할 수 있습니다. 다른 앱이 장치를 점유하면 단독 모드는 사용할 수 없습니다. 입력/출력 장치, 샘플 레이트, 버퍼 크기를 지정하세요. 설정이 실패하면 오류를 표시하고 이전 구성으로 되돌립니다. 자세한 오류는 로컬 errors.log에 기록됩니다.

오디오·MIDI·프로젝트 가져오기

파일을 편곡 화면에 드래그 앤 드롭하세요. 오디오 트랙에 놓으면 포인터 시간에 오디오를 배치하고 MIDI 파일은 편집 가능한 악기 리전이 됩니다. WAV는 직접 지원합니다. MP3, FLAC, AIFF, OGG, M4A는 PATH의 FFmpeg가 필요합니다. 파일 → 열기에서도 .flp, .als, .dawproject, 표준 MIDI를 열 수 있습니다. FLP는 패턴 노트, 플레이리스트 위치, 찾을 수 있는 샘플 참조를 가져옵니다. FL 악기, 프리셋, 믹서 라우팅, 스트레칭, 오토메이션은 재현하지 않습니다. 미할당 MIDI 트랙은 듣기 전에 라이브러리에서 소리를 선택하세요.

노트와 리전 편집

리전 본체를 드래그해 이동하고 가장자리를 드래그해 길이를 조정합니다. MIDI 리전을 더블클릭하면 피아노 롤이 열립니다. 격자를 클릭해 노트를 추가하고 드래그해 이동하며 오른쪽 끝으로 길이를 바꾸고 우클릭해 삭제합니다. 악보와 스텝 시퀀서도 같은 MIDI 노트를 편집합니다. 프로젝트 편집은 실행 취소와 다시 실행을 지원합니다.

Slop Launcher

셀의 상황에 맞는 메뉴에서 선택한 리전을 할당합니다. 셀이나 장면을 클릭하면 마디 경계에서 시작하도록 예약합니다. 클립은 다른 셀이나 정지를 선택할 때까지 반복됩니다. 편곡으로 돌아가기를 누르면 타임라인으로 복귀합니다. 셀 직접 녹음과 연주 내용을 편곡에 기록하는 기능은 없습니다.

내장 이펙트와 플러그인

플러그인 관리자는 악기/이펙트, 제조사, 형식으로 필터링합니다. 검색 경로를 다시 검색하면 실제 64비트 VST3/CLAP 플러그인을 찾습니다. 내장 이펙트는 5밴드 Visual Equalizer, Compressor, Saturator, Limiter, EDM Ducker, Stereo Imager입니다. 믹스 → 트랙 이펙트에서 내장 체인을 편집합니다. Ducker는 박자 동기화 자동 모드, MIDI 노트 온, 녹음 입력 오디오 사이드체인을 지원합니다. 플러그인은 두 블록 파이프라인을 통해 장치 콜백 밖에서 처리하며 트랙 간 지연을 동적으로 보정합니다. 오류가 난 플러그인의 트랙 자체는 무음이 될 수 있습니다.

확장을 제공하는 VST3 플러그인에서 ARA 2를 사용할 수 있습니다. 실제 WAV 리전이 있는 오디오 트랙에 불러오세요. 호스트는 임의 접근 오디오, 리전, 템포, 박자표 및 ARA 문서 아카이브를 제공합니다. Melodyne은 오디오 출력과 아카이브 복원까지 검증했습니다. Synthesizer V Studio 2 ARA는 문서 연결과 전용 편집기 표시를 확인했지만 보컬 합성 및 편집된 문서의 비어 있지 않은 아카이브는 아직 검증되지 않았습니다. 음성과 노트는 플러그인 편집기에서 설정해야 합니다.

피치, 타이밍 및 컴핑

파형 편집기는 Pitch와 Timing 모드를 제공합니다. Timing은 오디오 트랜지언트를 감지하고 원본 템포를 추정합니다. 불규칙한 리듬, 누락된 어택, 당김음은 추정을 왜곡할 수 있으므로 렌더링 전에 원본 BPM을 확인하세요. 그리드와 보정 강도를 설정하거나 주황색 대상 마커를 드래그할 수 있습니다. 스테레오를 연동하는 파형 유사도 기반 중첩 합성으로 음정을 유지하며 타이밍을 변경합니다. 학습된 AI 모델이 아닌 일반 DSP 처리입니다. 렌더링은 새 WAV 테이크를 만들고 원본 리전을 음소거하며 두 변경을 한 번에 실행 취소할 수 있습니다. 분석은 120초로 제한됩니다. 컴핑은 실제 테이크 구간을 선택하지만 완전한 자동 테이크 폴더는 아직 미완성입니다.

저장·바운스·자동 복구

지원하는 프로젝트 내용과 플러그인 상태를 저장합니다. 외부 WAV 파일은 참조 위치에 있어야 하며 저장 시 모든 미디어를 자동 수집하지는 않습니다. 바운스는 지정한 박 구간과 테일을 16/24비트 PCM 또는 32비트 float WAV로 내보냅니다. 자동 복구는 순환 스냅샷을 보관하며 비정상 종료된 세션을 다음 시작 때 제시합니다.

게임 컨트롤러와 음악 입력 키보드

디스플레이 설정에서 XInput/DirectInput 탐색을 켜세요. Slop가 활성 상태일 때만 동작합니다. A 재생/정지, B 정지, X 녹음, Y 음악 입력 키보드, LB/RB 한 마디 이동, Back 믹서, Start 설정, 방향 패드 트랙/마디 이동, 왼쪽 스틱 화면 이동, 오른쪽 스틱 위아래 확대/축소입니다. 장치별 배치는 다를 수 있습니다. 음악 입력 키보드는 A W S E D F T G Y H U J K를 사용하며 Z/X는 옥타브, C/V는 벨로시티를 바꿉니다. 닫거나 포커스를 잃으면 누른 노트를 해제합니다.

Lua 모드

모드 메뉴에서 명시적으로 선택한 .lua 파일을 불러옵니다. 표준 Lua 5.4 문법, 반복문, 테이블, 문자열, 수학을 지원합니다. 격리된 워커에는 메모리·명령·시간 제한이 있으며 파일, OS, 패키지, 네트워크 라이브러리를 제공하지 않습니다. 명령을 검증하고 한 번에 실행 취소할 수 있는 편집으로 적용합니다. 현재 API는 프로젝트 매크로용이며 임의의 네이티브 플러그인이나 완전한 사용자 UI 시스템은 아닙니다.

local track = slop.call("create_track", {name="Lua Arpeggio", type="midi"})
slop.call("set_tempo", {bpm=128})
for step=0,15 do
  slop.call("add_midi_note", {
    trackId=track.trackId, start=step*0.25, duration=0.2,
    pitch=60+({0,4,7,12})[(step % 4)+1], velocity=96
  })
end

추가 기능: 설정의 마지막 고급 탭에 엉망으로 만들기가 숨겨져 있습니다. 직접 합성한 폭발음과 떨어지는 리전을 표시합니다. Space 키로 화면을 복원하며 프로젝트 데이터는 변경하지 않습니다.

OSC·Link·MCP

OSC는 localhost UDP 9001에서 수신하고 보통 VRChat UDP 9000으로 송신합니다. 알려진 Slop 명령 주소에만 반응합니다. VRChat OSC는 사용자가 미리 켜 두어야 하며 Slop는 VRChat 설정을 읽거나 변경하지 않습니다. Link는 템포와 시작·정지를 공유하지만 샘플 클록의 완전한 위상 추종은 미완성입니다. SlopStudio.exe --mcp로 11개 stdio 도구를 가진 별도의 보이는 DAW 프로세스를 시작합니다.

알려진 제한

기능을 확장한 워크스테이션이지만 완성된 the referenced application 클론은 아닙니다. 모든 제조사 플러그인 호환, 전체 키 명령, 모니터 간 DPI 전환, 고급 악보 조판, 완전한 테이크 폴더, Debian 버전은 미완성 또는 미검증입니다. 동봉된 기능 목록과 시험 보고서를 확인하세요.

이 소프트웨어는 농담으로 제작되었습니다. 제작자 및 배포자는 사용으로 인한 어떠한 결과에 대해서도 책임을 지지 않습니다.

0.13 추가 기능

파일 → MIDI 내보내기로 음표, 템포, 박자를 표준 MIDI로 저장합니다. 피아노 롤 아래 벨로시티 막대를 드래그하고 실행 취소할 수 있습니다. 오른쪽 위 사각 슬라이더는 스테레오 마스터 음량을 조절합니다.

샘플 북마크와 즐겨찾기는 경로만 저장하며 원본을 이동하지 않습니다. 검색은 현재 폴더 또는 즐겨찾기 목록에 적용되며 하위 폴더는 검색하지 않습니다.

프로젝트를 템플릿으로 저장하면 .sloptemplate이 만들어집니다. 템플릿과 기본 예제는 저장되지 않은 복사본으로 열리며 새 .slopdaw 파일로 저장합니다. 오디오 파일은 경로로 연결됩니다.

환경설정에서 실행 취소 횟수, 테마 프로필(.sloptheme), 단축키 프로필(.slopkeys)을 변경할 수 있습니다. 테마는 다시 시작한 후 공통 UI에 적용되며 일부 이전 창은 자체 색상을 유지합니다. F11은 전체 화면을 전환합니다.

Launchpad X / Mini MK3의 MIDI 입출력을 선택하고 기기에서 프로그래머 모드를 켭니다. 첫 8개 표시 트랙과 8개 장면을 제어합니다. 파랑은 셀, 빨강은 대기, 초록은 재생입니다. 실제 기기와 다른 모델은 미검증이며 페이지 전환은 없습니다.

프로젝트 정보는 WAV 또는 MP3 메타데이터에 저장됩니다. MP3에는 외부 FFmpeg와 libmp3lame이 필요합니다. 스템은 새 폴더에 라우팅과 마스터 처리를 포함해 저장됩니다. 비선형 마스터에서는 스템 합계가 스테레오 믹스와 다를 수 있으며 버스와 하위 트랙을 함께 더하면 중복됩니다.

샘플 BPM 자동 맞춤, 트랙 프리즈와 다른 DAW의 기본 단축키 프리셋은 아직 구현되지 않았습니다.
