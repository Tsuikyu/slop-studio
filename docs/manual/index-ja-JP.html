Studio 0.9：ミキサーとトラックスタック

ミキサーでは付属エフェクトとVST3／CLAPが同じインサート列に表示されます。左クリックで編集、右クリックでバイパス／削除、同じチャンネル内のスロットへドラッグして順番を変更できます。センド +からAuxを作成し、ポストフェーダー送信と音量を設定できます。EDM DuckerはAudioトリガーにトラック信号を選択できます。外部プラグインへのサイドチェイン入力は未対応です。

Shiftで複数トラックを選び、トラックヘッダーの右クリックメニューからフォルダースタックまたはサミングスタックを作成します。サミングは子トラックの音を親のミキサーチャンネルに送ります。親の矢印で子を表示／非表示にします。ネストしたスタックは未対応です。

同一トラック上で複数リージョンを選び、Ctrl+Jまたは右クリックで統合できます。音声は新しいWAVを作成し、元のファイルを残します。Launcherやコンピングで使われているリージョンは統合できません。ルーラーの上端をドラッグしてループ範囲を作成し、両端をドラッグして変更します。ピアノロールのShift+ホイールは横移動です。

SamplerのImport Sampleで音声を読み込み、Record Sampleで選択した入力から録音し、RootとADSRを調整できます。録音には動作する入力デバイスが必要です。再生経路の遅延補償はスタック／Auxの分岐を考慮しますが、外部サイドチェインやあらゆるプラグイン構成での完全な補償は未検証です。

Studio 0.8：選択・MIDI・グローバルトラック

ポインターツールでドラッグすると、ノートを囲んで範囲選択できます。Shiftクリックは選択の追加・解除、Altドラッグは選択したノートの複製です。空白をダブルクリックするか、鉛筆を有効にするとノートを作成できます。Ctrl用ツールは「範囲選択・鉛筆・消しゴム」から選択します。Ctrl+A／C／X／Vはマウス下のエディターに作用し、それ以外の場所ではフォーカス中のエディターを使います。ペースト先は再生ヘッド位置です。矢印キーでノートを移動、Shift+上下でオクターブ移動、Ctrl+上下で縦ズーム、Ctrl+左右で横ズームします。Zで選択範囲または全体にズームし、再度押すと元の表示に戻ります。Shift+Iは選択の反転です。

Ctrl+ホイールはマウス下のエディターを拡縮し、Shift+ホイールは横スクロールします。Ctrl+Alt+ホイールでワークスペース全体の倍率を変更します。環境設定の「表示」で、マウス・トラックパッド・タッチスクリーン・XInput／DirectInputコントローラーを選択できます。タッチスクリーンモードでは2本指のパンとピンチに対応します。1本指によるマウス互換の編集も使えます。iPad版の全操作を再現するものではありません。実機タブレットと複数モニター間DPI移動は未検証です。

MIDIは録音待機なしでも、選択中のソフトウェア音源で試奏できます。ノートを録音する場合はトラックの録音待機を有効にしてください。「表示 → MIDI入力モニター」で入力機器・受信件数・短いMIDIメッセージを確認できます。複数ポートのある鍵盤は、補助コントロール用ではなくノート出力用のポートを選択してください。テストではKeystation 49の実ポートを開きましたが、物理打鍵の動作確認は別途必要です。

緑のSamplerスロットを左クリックすると、実際のPCM波形・ルート音のマッピング・試奏鍵盤を表示します。右クリックすると、Samplerプリセットまたはインストール済みのVST3／CLAP音源へ置き換えられます。内蔵バンクは独自生成したPCMマルチサンプルです。the vendorの音源素材は使用していません。EXSライブラリや本家Samplerの全変調機能には対応していません。

Gキー、またはリージョン欄上端の細い境界線を下へドラッグして、グローバルトラックを表示します。ダブルクリックでテンポ・拍子・コード進行を編集します。コードは「Am | Fmaj7 | C | G」のように区切って入力します。「コードのMIDIトラックを作成」を選ぶと、実際に編集・再生できるノートを生成します。Session Player音源や可変テンポオートメーションの完全実装ではありません。コンピングでは、オーディオとMIDIテイクの範囲を選択できます。

読み込み・ムービー・サンプル

「ファイル → 開く」とプロジェクト読み込みは、.slopdaw／.mid／.midi／.flp／.als／.dawprojectを扱います。MIDIのD&Dはトラックやリージョンを追加し、プロジェクトとして開く場合はテンポ・拍子も引き継ぎます。FLP／ALSは対応範囲の限られた変換です。読み込んだノートはSamplerで試聴できますが、元のベンダー音源・プリセット・ワープ・全ルーティングを復元したものではありません。「表示 → 読み込みレポート」で変換時の警告を確認できます。すべてのFLP／ALSへの互換性は保証していません。

ムービー読み込みはMP4／MOVなど、FFmpegでデコードできる形式を扱います。外部ムービーへの参照を保存し、音声があれば取り出し、再生ヘッドに同期するプレビューを開きます。FFmpegはPATH上、SlopStudio.exeの隣、または環境変数SLOPX_FFMPEGで指定してください。任意の外部依存であり、この配布物には同梱していません。プレビューは約165 ms間隔の非同期フレーム取得による位置合わせ用で、フルフレームレートの動画編集機能ではありません。プロジェクト保存時に外部動画を自動収集しません。

クイックスタートから「EDM Sample - Melodic House」を開けます。8トラック・64小節の独自サンプルで、Sampler、MIDIノート、コード、Launcher割り当て、オートメーション、内蔵FXを含みます。外部音源プラグインは不要です。

内蔵FXはロータリーノブと特性・エンベロープ表示を備えます。曲線は設定値に基づき、メーターは実際のDSP値を表示します。「ヘルプ → MIT Licences」で配布するMITライセンスの原文全文を確認できます。「なめらかなUIアニメーション」は表示更新間隔を短くする設定で、音声処理は変更しません。

音声障害への対応と検証範囲

ASIOの起動通知とオーディオバッファの応答を分離しました。同じサンプルレートの通知と再同期要求では再生を停止しません。ドライバープロセス終了やコールバック停止を検出して通知し、再生ボタンで接続をやり直します。実際のFL Studio ASIOで連続再生・パン変更・シーク・再接続を検証しました。すべてのドライバーや、デバイスリセット中の無停止音声を保証するものではありません。WASAPI共有モードは検証済みですが、排他モードはエンドポイントに依存します。

プロジェクトを作成し、音声を設定し、素材を追加して、編曲とミックスを行います。このマニュアルは本ビルドの機能を説明するもので、the referenced applicationとの完全な互換性を示すものではありません。

使い始める

アプリのフォルダー全体を展開してSlopStudio.exeを起動します。クイックスタートから、空のプロジェクト、実際に発音するSlop Launcherのスターター、First Lightの作例、デバイス設定を開けます。制作内容は.slopdaw形式で保存します。

画面の移動とサイズ変更

Ctrl＋ホイールは、カーソル下のアレンジメントまたはピアノロールだけをズームし、カーソル位置の拍を保ちます。Shift＋ホイールは横移動、通常のホイールは縦移動です。Ctrl＋Alt＋ホイールは全体倍率を1%ずつ変更します。再生ヘッドやルーラーをドラッグして位置を変更でき、端に寄せると画面がスクロールします。パネルの境界は幅8ピクセルの範囲でつかめます。

再生と録音

Spaceで再生／停止、テンキー0で停止、Returnで停止して先頭へ戻ります。Rは録音待機中のトラックに録音します。音声は「録音 → 入力ルーティング／監視」で入力を割り当て、対象トラックを録音待機にしてください。利用可能な実入力が必要です。停止するとWAVを確定し、リージョンを作成します。Ctrl＋Kでソフトウェア鍵盤を開くと、実物の鍵盤なしでMIDIを演奏・録音できます。

オーディオ設定

Windowsの共有音声にはWASAPIを選びます。インストール済みの64 bit ASIOドライバーも選択できます。ほかのアプリがデバイスを占有している場合、排他モードは使用できません。入出力デバイス、サンプルレート、バッファサイズを指定します。設定に失敗した場合はエラーを表示し、以前の構成へ戻します。エラーの詳細はローカルのerrors.logに記録されます。

音声・MIDI・プロジェクトの読み込み

ファイルをアレンジメントへドラッグ＆ドロップします。オーディオトラック上に落とすと、カーソル位置へ音声を配置します。MIDIファイルは編集可能な音源リージョンになります。WAVは直接読み込めます。MP3、FLAC、AIFF、OGG、M4AはPATH上のFFmpegが必要です。「ファイル → 開く」から.flp、.als、.dawproject、標準MIDIも開けます。FLPはパターンのノート、プレイリスト位置、解決可能なサンプル参照を読み込みます。FL音源、プリセット、ミキサー経路、ストレッチ、オートメーションは再現しません。未割当のMIDIトラックは、試聴前にライブラリでサウンドを選んでください。

ノートとリージョンを編集する

リージョンの本体をドラッグして移動し、端をドラッグして長さを調整します。MIDIリージョンをダブルクリックするとピアノロールが開きます。グリッドをクリックしてノートを追加し、ドラッグで移動、右端で長さ変更、右クリックで削除します。譜面とステップシーケンサーも同じMIDIノートを編集します。プロジェクトの編集は取り消し・やり直しに対応します。

Slop Launcher

セルのコンテキストメニューから、選択したリージョンを割り当てます。セルやシーンをクリックすると、小節境界での再生開始を予約します。クリップは別セルや停止を選ぶまで繰り返します。「アレンジメントに戻る」でタイムラインへ戻ります。セルへの直接録音と、演奏のアレンジメント記録には対応していません。

付属エフェクトとプラグイン

プラグインマネージャーは音源／エフェクト、メーカー、形式で絞り込めます。検索パスを再スキャンすると実際の64 bit VST3／CLAPプラグインを検出します。付属品は5バンドのVisual Equalizer、Compressor、Saturator、Limiter、EDM Ducker、Stereo Imagerです。「ミックス → トラックエフェクト」で付属チェーンを編集します。Duckerは拍同期の自動、MIDIノートオン、録音入力からの音声サイドチェインに対応します。プラグインは2ブロックの経路を通してデバイスコールバックの外で処理し、トラック間の遅延を動的に補償します。故障したプラグインのトラック自体は無音になる場合があります。

拡張を公開するVST3プラグインでARA 2を利用できます。実際のWAVリージョンがあるオーディオトラックへ読み込んでください。ホストはランダムアクセス音声、リージョン、テンポ、拍子、ARAドキュメントの保存領域を提供します。Melodyneでは音声出力とアーカイブの復元まで検証しました。Synthesizer V Studio 2 ARAはドキュメント接続と専用GUIの表示を確認しましたが、歌声合成と編集済みドキュメントの空ではない保存データは未検証です。歌声とノートの設定はプラグイン側で行います。

ピッチ・タイミング・コンピング

波形エディターにはPitchとTimingがあります。Timingは音声のアタックを検出し、素材のテンポを推定します。変則的なリズム、抜けたアタック、シンコペーションでは誤推定するため、レンダー前に素材のBPMを確認してください。グリッドと補正量を指定するほか、オレンジ色の移動先マーカーをドラッグできます。左右チャンネルを連動した波形類似度による重ね合わせで、音高を維持しながら時間を変更します。学習済みAIモデルではなく、通常のDSP処理です。レンダーは新しいWAVテイクを作り、元のリージョンをミュートします。この2操作は一度のUndoで戻せます。解析は120秒までです。コンピングは実際のテイクの範囲選択に対応し、自動テイクフォルダー全体の機能は未完成です。

保存・マスター書き出し・自動復旧

対応するプロジェクト内容とプラグイン状態を保存します。外部WAVは参照先に残す必要があり、保存時にすべての素材を自動収集する機能はありません。マスター書き出しは指定した拍範囲とテールを、16／24 bit PCMまたは32 bit float WAVとして書き出します。自動復旧は世代スナップショットを保持し、異常終了したセッションを次の起動時に提示します。

コントローラーとソフトウェア鍵盤

表示設定でXInput／DirectInput操作を有効にします。Slopがアクティブな間だけ動作します。Aは再生／停止、Bは停止、Xは録音、Yはソフトウェア鍵盤、LB／RBは1小節移動、Backはミキサー、Startは設定、十字キーはトラック／小節移動、左スティックは画面移動、右スティックの上下はズームです。機種によって配置が異なります。ソフトウェア鍵盤はA W S E D F T G Y H U J Kを使い、Z／Xでオクターブ、C／Vでベロシティを変更します。閉じたときやフォーカスを失ったときは押下中のノートを解放します。

Lua Mod

Modメニューから明示的に選んだ.luaファイルを読み込みます。標準Lua 5.4の構文、ループ、テーブル、文字列、数学を利用できます。独立したワーカーにはメモリー・命令数・時間の制限があり、ファイル、OS、パッケージ、ネットワークのライブラリは公開しません。コマンドを検証し、1回で取り消せる編集として適用します。現行APIはプロジェクトのマクロ向けで、任意のネイティブプラグインや本格的な独自UIシステムではありません。

local track = slop.call("create_track", {name="Lua Arpeggio", type="midi"})
slop.call("set_tempo", {bpm=128})
for step=0,15 do
  slop.call("add_midi_note", {
    trackId=track.trackId, start=step*0.25, duration=0.2,
    pitch=60+({0,4,7,12})[(step % 4)+1], velocity=96
  })
end

おまけ：環境設定の最後にある「詳細」→「追加のおまけ」に「めちゃくちゃにする」があります。独自合成した爆発音とリージョン落下を表示し、Spaceで復帰します。プロジェクトのデータは変更しません。

OSC・Link・MCP

OSCはlocalhostのUDP 9001で受信し、通常はVRChatのUDP 9000へ送信します。既知のSlopコマンドにだけ応答します。VRChat側のOSCはユーザーがあらかじめ有効にしておく必要があり、SlopがVRChatの設定を読んだり変更したりすることはありません。Linkはテンポと開始・停止を共有しますが、サンプルクロックの完全な位相追従は未完成です。SlopStudio.exe --mcpで、11個のstdioツールを持つ別の可視DAWプロセスが起動します。

既知の制限

機能を拡張したワークステーションですが、完成したthe referenced applicationクローンではありません。全メーカーのプラグイン互換、すべてのキーコマンド、モニター間のDPI移動、高度な譜面整形、完全なテイクフォルダー、Debian版は未完成または未検証です。同梱の機能台帳と試験報告を参照してください。

0.13 の追加操作

「ファイル → MIDIを書き出す」で、トラックのノート、テンポ、拍子を標準MIDIとして保存します。ピアノロール下部のベロシティを上下にドラッグし、Ctrl+Zで戻せます。右上の角形スライダーはステレオ出力の音量に連動します。

サンプルブラウザーの「フォルダーを登録／解除」と「お気に入り追加／解除」はパスだけを記録し、素材を移動しません。検索は現在のフォルダーまたはお気に入りの一覧に適用されます。サブフォルダーの再帰検索には対応していません。

「プロジェクトをテンプレートとして保存」は .sloptemplate を作ります。同梱サンプルとテンプレートを開くと未保存のコピーになり、保存には新しい .slopdaw ファイルを指定します。音声素材は参照のままです。

環境設定の「プロジェクト」でUndo回数、「表示」でテーマ、「キーコマンド」でショートカットを編集できます。テーマとキーのプロファイルはそれぞれ .sloptheme、.slopkeys として保存・読み込みできます。テーマは再起動後に共通部品に反映され、独自描画の一部は既定色のままです。F11で全画面を切り替えます。

Launchpad X / Mini MK3 のMIDI端子を環境設定で指定し、本体をProgrammerモードに切り替えると、上から8トラック、左から8シーンのセルを操作します。空セルは無反応、青は割当、赤は待機、緑は再生中です。実機と他モデルは未検証で、ページ切り替えはありません。

「プロジェクト情報」はWAVまたはMP3書き出しの情報として保存されます。MP3には外部FFmpegとlibmp3lameが必要です。ステムは新規フォルダーへ個別に書き出し、各ファイルにその経路とマスター処理を適用します。非線形マスター処理によりステムの合計はステレオミックスと一致しない場合があり、バスと子トラックを同時に足すと重複します。

素材のBPM検出・自動追従、トラックのフリーズ／解除、他社DAWの公式ショートカットプリセットは未実装です。
