Studio 0.9: mixer and track stacks

Built-in effects and VST3/CLAP effects share the channel insert list. Left-click to edit, right-click to bypass or remove, and drag to reorder within a channel. Send + creates or configures post-fader Aux sends. EDM Ducker can use a track as its audio trigger; external plug-in sidechain inputs are not supported.

Shift-select track headers and use the right-click menu to create a folder or summing stack. A summing stack routes child audio through its parent mixer channel; use the disclosure arrow to hide or show children. Nested stacks are not supported.

Select multiple regions on one track and use Ctrl+J or the context menu to join them. Joining audio creates a new WAV and keeps source files. Regions used by Launcher or comping cannot be joined. Drag the top of the ruler to set a cycle range, and drag its edges to resize it. Shift+wheel scrolls the piano roll horizontally.

Sampler imports audio, records from the selected working input, and offers root-note and ADSR controls. Routing-aware delay compensation aligns audio at stack and Aux buses; compensation of external sidechain keys and all plug-in configurations has not been verified.

Studio 0.8: selection, MIDI and global tracks

Use the Pointer tool to drag a rectangle around notes. Shift-click adds or removes notes; Alt-drag copies the selected group. Double-click empty piano-roll space to create a note, or turn on Pencil. The Ctrl tool menu chooses Marquee, Pencil or Eraser. Ctrl+A, Ctrl+C, Ctrl+X and Ctrl+V operate in the editor under the pointer, falling back to the focused editor. Paste inserts at the playhead. Arrow keys move selected notes; Shift+Up/Down transposes an octave. Ctrl+Up/Down zooms vertically; Ctrl+Left/Right zooms horizontally. Z fits the selection or contents and restores the previous view on the next press. Shift+I inverts selection.

Ctrl+wheel zooms the editor under the pointer. Shift+wheel scrolls horizontally. Ctrl+Alt+wheel changes workspace scale. In Settings → Display, choose Mouse, Trackpad, Touchscreen, XInput Controller or DirectInput Controller. Touchscreen mode handles two-finger pan and pinch; single-finger mouse-compatible editing remains available. This does not reproduce the complete tablet interface. Physical tablet and mixed-monitor DPI behavior have not been verified.

MIDI now plays the selected software instrument without record-enable. Arm a track to record notes. View → MIDI Input Monitor shows the configured device, message count and incoming short MIDI messages. If the keyboard exposes multiple ports, select its note port, not an auxiliary control port. The physical Keystation 49 input was opened in testing; actual key performance still requires verification.

Left-click the green Sampler slot for the original PCM waveform/mapping editor and playable keyboard. Right-click the slot to replace it with a Sampler preset or an installed VST3/CLAP instrument. The built-in bank contains original generated PCM multisamples, not the vendor samples. EXS libraries and the full reference application Sampler modulation system are unsupported.

Press G, or pull down the narrow top edge of the arrangement, to reveal Global Tracks. Double-click to edit tempo, meter and a chord progression. Use | to separate chords, for example Am | Fmaj7 | C | G. “Create MIDI chord track” writes real editable notes. This is not a Session Player engine or a variable-tempo automation map. Comping can select ranges from audio and MIDI takes.

Imports, movies and sample project

File → Open and project import accept .slopdaw, .mid, .midi, .flp, .als and .dawproject. Dropping MIDI appends tracks or regions; opening it as a project restores the imported tempo/meter. FLP/ALS import is a documented subset. Imported notes use Sampler for audition; original vendor devices, presets, warps and complete routing are not recreated. View → Import Report retains conversion warnings. No universal FLP/ALS compatibility is claimed.

Import Movie accepts MP4/MOV and other FFmpeg-readable movies. It stores a movie reference, extracts an available audio stream and opens a preview tied to the playhead. FFmpeg must be on PATH, beside SlopStudio.exe, or selected with SLOPX_FFMPEG. FFmpeg is optional and is not bundled. Preview uses asynchronous frame decoding, with approximately 165 ms scheduling; it is an alignment aid, not a full-rate video editor. Project saving does not collect external movie media.

Quick Start includes EDM Sample - Melodic House: an original eight-track, 64-bar arrangement with Sampler instruments, MIDI notes, chords, launcher assignments, automation and stock effects. No external instrument plug-ins are required.

The stock effects now use rotary controls and a transfer/envelope display. Display curves describe current parameter settings; meters read actual DSP values. Help → MIT Licences displays the complete distributed MIT licence texts unchanged. Smooth UI animation selects a faster transport refresh interval; it does not change audio processing.

Audio recovery and verified scope

ASIO startup and buffer acknowledgements use separate IPC events. Same-rate notifications and resync requests no longer stop playback. If the driver process exits or stops sending buffers, the application reports the failure; Play reconnects the failed ASIO device. A real FL Studio ASIO driver passed sustained playback, graph changes, seeking and restart tests. This does not guarantee every driver or uninterrupted audio during device reset. WASAPI shared mode was verified; exclusive-mode support remains dependent on the endpoint.

Create a project, configure audio, add material, then arrange and mix it. This guide documents the capabilities of this build; it does not claim complete the referenced application compatibility.

Getting started

Extract the complete application folder and run SlopStudio.exe. Quick Start offers an empty project, a playable Slop Launcher starter, the First Light example and device settings. Save your work as a .slopdaw project.

Navigate and resize

Ctrl + wheel zooms only the arrangement or piano roll under the pointer, keeping the musical position under the pointer stable. Shift + wheel moves the view horizontally. Wheel scrolls vertically. Ctrl + Alt + wheel changes the whole workspace in 1% steps. Drag the playhead or ruler to seek; holding it at an edge scrolls the view. Drag an 8-pixel panel divider to resize it.

Playback and recording

Space toggles playback. Numeric keypad 0 stops; Return stops and returns to the beginning. R records to armed tracks. For audio, choose an input route under Record → Input Routing / Monitoring, then arm the destination track. A real input must be available. Stop finalizes the recorded WAV and creates a region. Ctrl+K opens Musical Typing for playing and recording MIDI without a hardware keyboard.

Audio settings

Choose WASAPI for Windows shared audio, or an installed 64-bit ASIO driver. Exclusive mode may be unavailable when another application owns the endpoint. Choose matching input/output endpoints, sample rate and buffer size. An invalid configuration is reported and the previous settings are restored. Device errors are logged locally in errors.log.

Import audio, MIDI and projects

Drop files directly onto the arrangement. Dropping on an audio track places audio at the pointer time; MIDI files become editable instrument regions. WAV works directly. MP3, FLAC, AIFF, OGG and M4A require FFmpeg on PATH. File → Open also accepts .flp, .als, .dawproject and standard MIDI. FLP imports pattern notes, playlist timing and resolvable sample references. FL instruments, presets, mixer routing, stretching and automation are not recreated. Assign sounds in the Library before auditioning unassigned MIDI tracks.

Edit notes and regions

Drag a region body to move it and its edges to trim it. Double-click a MIDI region to open the piano roll. Click the grid to enter notes, drag notes to move, drag their right edge to change duration, and right-click to delete. Score and Step Sequencer edit the same stored MIDI notes. Undo and Redo apply to project edits.

Slop Launcher

Assign a selected region to a cell using its context menu. Click a cell or scene to queue playback at a bar boundary. Clips loop until another cell or stop is chosen. Return to Arrangement resumes the timeline. Direct recording into cells and performance capture are not implemented.

Included effects and plug-ins

The Plug-in Manager filters by instrument/effect, vendor and format. Rescan configured VST3/CLAP folders to discover real 64-bit plug-ins. Slop includes a five-band Visual Equalizer, Compressor, Saturator, Limiter, EDM Ducker and Stereo Imager. Edit the included chain under Mix → Track Effects. EDM Ducker offers beat-synced Auto, MIDI note-on triggering and capture-input Audio sidechain modes. Plug-in processing runs outside the device callback through a two-block pipeline; track latency is compensated dynamically. A failed plug-in can still silence its own track.

ARA 2 is available for VST3 plug-ins that advertise the extension. Load one on an audio track with a real WAV region. The host supplies random-access audio, regions, tempo, meter and an ARA document archive. Melodyne was tested with rendering and archive restoration. Synthesizer V Studio 2 ARA opened its editor and accepted the document, but vocal synthesis and nonempty edited-document archives remain unverified. The singing voice and note content still have to be provided in the vendor editor.

Pitch, timing and comping

Waveform Editor offers Pitch and Timing modes. Timing detects audio transients and estimates a source tempo. Review Source BPM before rendering: irregular rhythms, missing attacks and syncopation can mislead the estimate. Set the grid and strength, or drag orange destination markers. Stereo-linked waveform-similarity overlap-add changes timing while preserving pitch; it is conventional DSP, not an AI model. Rendering creates a new WAV take, mutes the original and commits both changes as one undoable edit. Analysis is limited to 120 seconds. Comping selects actual take ranges; full automatic take folders remain incomplete.

Save, bounce and recovery

Save stores supported project content and plug-in states. Referenced external WAV files must remain available; saving does not collect all media automatically. Bounce exports a selected beat range plus tail as 16/24-bit PCM or 32-bit float WAV. Recovery keeps rotating snapshots and offers an unclean session at the next start.

Game controllers and Musical Typing

Enable XInput / DirectInput navigation in Display settings. Controls act only while Slop is active: A play/stop, B stop, X record, Y Musical Typing, LB/RB one bar, Back mixer, Start settings, D-pad track/bar navigation, left stick view movement and right-stick vertical axis zoom. Device layouts may differ. Musical Typing uses A W S E D F T G Y H U J K; Z/X change octave, C/V velocity. Closing it or losing focus releases held notes.

Lua Mods

Load an explicitly chosen .lua file from Mods. Standard Lua 5.4 syntax, loops, tables, strings and math are supported. The isolated worker has memory/instruction/time limits and no file, OS, package or network library. Mod commands are validated and committed as one undoable edit. The current API supports project macros, not arbitrary native plug-in code or a full custom-UI system.

local track = slop.call("create_track", {name="Lua Arpeggio", type="midi"})
slop.call("set_tempo", {bpm=128})
for step=0,15 do
  slop.call("add_midi_note", {
    trackId=track.trackId, start=step*0.25, duration=0.2,
    pitch=60+({0,4,7,12})[(step % 4)+1], velocity=96
  })
end

Optional extras: the last Advanced settings tab hides Make a mess. It plays an original synthesized explosion and shows falling regions. Space restores the view; project data is never changed.

OSC, Link and MCP

OSC receives on localhost UDP 9001 and sends to the configured destination, normally VRChat UDP 9000. Only known Slop command addresses are acted on. VRChat OSC must already be enabled by the user; Slop does not inspect or change VRChat settings. Link shares tempo and start/stop; full sample-clock phase following is incomplete. Launch SlopStudio.exe --mcp for a separate visible DAW process with eleven stdio tools.

Known limits

This is a substantial but incomplete workstation. It is not a complete the referenced application clone. All-vendor plug-in compatibility, full key-command parity, cross-monitor DPI transitions, advanced score engraving, full take folders and Debian support are not verified or complete. Refer to the capability ledger and test report shipped with this build.

New in 0.13

File → Export MIDI saves notes, tempo, and meter as a standard MIDI file. Drag the velocity bars under the piano roll and use Undo to restore them. The square control at the upper right changes the stereo master gain.

Sample bookmarks and favorites store references only; original files are not moved. Search filters the current folder or Favorites, not nested folders.

Save Project as Template creates a .sloptemplate. Opening a template or bundled example creates an unsaved copy; save it as a new .slopdaw file. Audio remains linked by path.

Preferences provide the undo limit, theme profiles (.sloptheme), and editable shortcut profiles (.slopkeys). Themes apply to shared controls after restart; some older custom windows retain their own colors. F11 toggles full screen.

For Launchpad X / Mini MK3, select the MIDI input and output and enable Programmer mode on the device. The grid maps the first eight visible tracks and eight scenes; blue indicates a populated cell, red a queued cell, and green a playing cell. Hardware and other models have not been verified. Paging is unavailable.

Project information is exported as WAV or MP3 metadata. MP3 needs an external FFmpeg with libmp3lame. Stem files are written to a new folder and include routing and master processing. A nonlinear master makes their sum differ from the stereo mix; adding both a bus and its children duplicates audio.

Automatic sample BPM matching, track freeze/unfreeze, and factory shortcut presets for other DAWs are not yet implemented.
