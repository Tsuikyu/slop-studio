# Slop Studio 0.7 shortcut compatibility

Exported from the actual command registry. An active handler is not proof that every key was individually exercised. The registry duplicate/conflict check passed. Space, numeric 0/decimal, Return, M and text-entry guards were exercised by GUI/transport tests; Ctrl+K opens Musical Typing. Many remaining Logic commands have no implementation. This is a documented subset, not a complete Logic preset.

Modifier policy: Command → Ctrl; Option → Alt; Control → Ctrl+Alt; Shift → Shift. Modifier sets are normalized, so repeated Alt is not duplicated. Context restrictions and deliberate adaptations are recorded per row. AppleUSFactoryPreset refers to the documented US factory preset; other origins are explicitly separate.
