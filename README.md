# Slop Studio 0.13 — 開発版

Slop Studio は Windows 11 x64 向けの音声・MIDI ワークステーションです。Minimal CyberSquare の黒と紫を基調とした独立した画面を使い、既存の編集・制作ワークフローを引き継ぎます。アプリは開発中であり、商用 DAW と同等の完成度や全プラグインとの互換性を保証するものではありません。

## 起動

配布フォルダー内の `SlopStudio.exe` を実行してください。Windows 11 x64 と .NET Framework 4.8 が必要です。初回はクイックスタートが開きます。起動画面は付属画像と、起動の実際の段階に応じて更新されるバーを表示します。画像が読めない場合は簡易画面に切り替わります。

## プロジェクト

新規・保存・読み込み・復旧の標準形式は **`.slopdaw`** です。MIDI、トラック、対応するプラグイン状態、インサート順、オートメーションなどを保存します。既存ファイルの上書き時は別名のバックアップを残します。オーディオ素材は参照であり、プロジェクトを移動・共有する際は素材の所在も維持してください。素材を自動収集する完全な機能はありません。詳細は [形式の説明](docs/slopdaw-format.md) を参照してください。

## 主な制作機能

- オーディオおよび MIDI のトラック、リージョン、ピアノロール、再生・録音、Undo / Redo。
- Sampler、内蔵 FX、VST3 / CLAP ホスト、トラックとマスターのインサート、ドラッグによる並べ替え、Aux・スタック。対応範囲はプラグインや信号経路ごとに異なります。
- 波形エディターのピッチ編集、グローバルトラックとコード、Slop Launcher、オートメーション、コンピング、動画プレビュー、MIDI ファイルと他社プロジェクトの限定的な読み込み。
- WASAPI および独立した ASIO 補助プロセス、Lua、OSC、ゲームコントローラー、stdio MCP。各機器・外部アプリとの互換性は個別確認が必要です。
- 日本語・英語・ドイツ語・韓国語のリソースとマニュアル。未翻訳の項目が残る可能性があります。

マスターの FX はミキサーの「ステレオ出力」またはインスペクターの出力ストリップから追加できます。内蔵 FX と外部プラグインは同じ順序付きチェーンで処理します。

「ファイル → マスター → プロジェクトまたは選択範囲をマスターとして書き出す」（Ctrl+B）から、マスター処理を含む WAV または MP3 を書き出せます。マスター処理の一括有効／無効と、参照音源の波形・試聴も同じメニューにあります。リージョン／トラックの元位置へのオーディオ化と、全トラックの置き換えは未実装のため無効表示です。

リージョン、トラックヘッダー、ミキサーストリップの右クリックで背景色と文字色を変更できます。サンプルブラウザーは素材を選ぶと波形を表示し、Windows の既定出力で試聴します。インスペクターの数値は上下ドラッグまたはホイールで変更できます。ASIO 選択時の設定ボタンからドライバーの設定画面を開けます。Lua Mod マネージャーは複数の `.lua` ファイルを登録し、選んだものを明示的に実行します。ゲームコントローラーのボタン割り当ては環境設定のキーコマンドから変更できます。

FLP 読み込みでは MIDI ノートと対応する配置、参照できる音声を取り込みます。見つからない音声は無音の `[Missing]` リージョンとして保持します。該当リージョンを右クリックし「音声ファイルを再リンク…」から WAV を指定すると、同じ参照先のリージョンも更新します。元の音源、FX、オートメーション、ルーティング、トリムや伸縮の完全な再現には対応していません。

## 0.13 での追加操作

- 右上の角形スライダーとステレオ出力のフェーダーは同じマスター音量です。「ファイル → MIDIを書き出す」で標準 MIDI を保存できます。ピアノロール下部ではベロシティ棒をドラッグして変更し、Undo で戻せます。
- サンプルブラウザーのブックマークとお気に入りはファイルの参照のみを保存します。検索は表示中のフォルダーまたはお気に入りに対して行われます。
- 「ファイル → プロジェクトをテンプレートとして保存」で `.sloptemplate` を作成します。テンプレートと同梱サンプルはアプリ内では未保存のコピーとして開き、新しい `.slopdaw` に保存します。音声の参照先は維持する必要があります。
- プロジェクト情報を WAV / MP3 のタグに出力できます。MP3 は別途 FFmpeg と libmp3lame が必要です。マスター画面のステム出力は新しいフォルダーに保存します。バスとその子トラックは重複し、マスターの非線形 FX によりステムの合計がミックスと異なる場合があります。
- 環境設定で Undo 回数、テーマ（`.sloptheme`）、ショートカット（`.slopkeys`）を設定できます。テーマは再起動後に共通色へ反映されます。一部の独自画面は固定色です。他社 DAW の公式プリセットは付属しません。F11 は全画面切り替えです。
- Launchpad X / Mini MK3 の Programmer モード向けに、MIDI 入出力を明示選択して先頭8トラック×8シーンを操作できます。ハードウェア実機とその他の機種は未検証です。
- 同梱例には 128 BPM の「EDM Sample - Melodic House」と 150 BPM の「J-Pop - Shibuya」があります。自動サンプル BPM 追従とトラックフリーズは未実装です。

## プラグイン画面とプリセット

プラグイン、内蔵 FX、Sampler の画面上部から、設定の保存・読み込み、コピー・貼り付け、画面を開いた時点との比較ができます。保存形式は Slop Studio 独自の `.sloppreset` です。コピーはアプリを終了するまで保持され、同じ種類のプラグインに貼り付けられます。外部プラグインのネイティブなプリセット形式との相互読み込みは実装していません。Sampler の外部サンプルはプリセットに埋め込まれず、ファイルの参照先が必要です。

Visual Equalizer は 5 バンドの周波数特性を表示し、グラフ上のポイントをドラッグすると実際のフィルターを編集できます。Sampler の Attack・Decay・Sustain・Release はつまみと数値の両方で調整できます。Compressor を含む内蔵 FX のパラメーター変更は再生中の処理へ反映されます。

MCP は通常起動時には停止しており、クライアントが `SlopStudio.exe --mcp` を起動した場合のみ stdio で利用します。最初は読み取りのみで、編集は「ウインドウ → MCP AI連携マネージャー」でセッションごとに許可します。ファイル操作や録音待機にはさらに都度確認があります。正式な MCP 相互運用性や包括的なセキュリティ監査は未検証です。

WAV 以外の一部の音声と動画には、別途インストールした FFmpeg が必要です。FFmpeg やサードパーティー製プラグインは同梱しません。FLP / ALS / DAWproject の全機能や全音源状態が再現されるわけではありません。

## ビルドとテスト

Windows 11 x64、CMake 3.24 以上、Ninja または MSVC、x64 C/C++ ツールチェーン、.NET Framework 4.8 の C# コンパイラーが必要です。付属 SDK と各ライセンスを保持してください。具体的なコマンドは [ビルドと検証](docs/build-and-test.md) を参照してください。

現状、Windows 以外のビルド、物理 MIDI キーボード・マイク・ASIO 機器の全組み合わせ、複数モニターの DPI、全ベンダーのプラグインは検証できていません。環境内の OSC ローカル UDP 受信は失敗しています。メニュー仕様の全項目が実装済みという意味ではありません。今回の検証と未完了は [機能・検証台帳](docs/status-v0.13-ja.md)、既存メニューの対応関係は [menu-command-map.json](docs/menu-command-map.json) に記録しています。
