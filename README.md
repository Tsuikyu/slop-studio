## これは何？

Slop Studioは、Windows向けのデジタル・オーディオ・ワークステーション（DAW）です。

作曲、編曲、録音、MIDI編集、ミキシング、音声書き出しを一つのアプリで実現することを目指しています。

Logic Proに慣れた人でも扱いやすいワークフローを参考にしていますが、Appleとは一切関係ありません。Appleの公式製品でもありません。

画面は黒と青紫を基調とした独自の **Minimal CyberSquare** デザイン。

旧名称は「Slop Pro X」。現在の正式名称は「Slop Studio」です。

標準プロジェクト形式は `.slopdaw`。かつての `.slopx` は廃止されました。過去は振り返りません。

商用DAWと競争できるのか？

**知りません。まだ0.13です。**

音楽を作るためのソフトですが、ときにはソフト自体を修理することになるかもしれません。それもまたSlop Studioです。

## 起動方法

配布フォルダーの `SlopStudio.exe` を実行してください。

必要な環境：

- Windows 11 x64
- .NET Framework 4.8
- 未完成ソフトウェアに対する多少の寛容さ

初回起動時にはクイックスタートが表示されます。

起動画面には専用画像と、実際の起動段階に応じて進むプログレスバーがあります。画像を読み込めなければ簡易画面に切り替わります。

起動に失敗した場合、残念ながら音楽制作は始まりません。

## プロジェクト：`.slopdaw`

Slop Studioは独自形式 `.slopdaw` でプロジェクトを保存します。

保存対象には、MIDI、トラック、対応するプラグイン状態、インサート順、オートメーションなどが含まれます。

新規作成、保存、読み込み、復旧に使用する標準形式です。

既存ファイルを上書きする際は別名のバックアップを残します。

**重要：音声ファイルは原則として参照方式です。**

つまり、プロジェクトだけを別のPCへコピーしても、音声素材が一緒に移動するとは限りません。

素材の自動収集機能もまだ完全ではありません。

「昨日まで鳴っていたキックが突然消えた」という事態を防ぎたいなら、音声ファイルの保存場所も管理してください。

詳しくは [`.slopdaw` 形式の仕様](docs/slopdaw-format.md) を参照してください。

Slop Studioには、以下の機能が存在します。

**基本的な制作**

- オーディオトラック、MIDIトラック
- リージョン編集、ピアノロール
- 再生、録音、Undo / Redo
- Sampler、内蔵エフェクト
- VST3 / CLAP プラグインホスト
- ミキサー、Aux、トラックスタック
- オートメーション、コンピング

- 日本語、英語、ドイツ語、韓国語のUIとマニュアル

未翻訳の表示が残っていたり、プラグインや信号経路によって動作範囲が異なったりします。

**「メニューにある」ことと「完全に動く」ことは別です。**

## ミキサーとエフェクト

内蔵FXと外部プラグインは、順序付きのインサートチェーンで処理します。

トラックとマスターのインサートに対応し、ドラッグによる順序変更もできます。

マスターFXは、ミキサーの「ステレオ出力」またはインスペクターの出力ストリップから追加できます。

Visual Equalizerは5バンドの周波数特性を表示し、グラフ上のポイントをドラッグしてフィルターを編集できます。

SamplerのADSRはつまみと数値で調整できます。Compressorなどの内蔵FXも、パラメーター変更を再生中の処理に反映します。

もっとも、実際の音声経路やプラグインとの組み合わせは、まだ検証すべき部分があります。

音が出たら制作開始。音が出なければデバッグ開始です。

## 書き出し：スロップを音声ファイルへ

「ファイル → マスター → プロジェクトまたは選択範囲をマスターとして書き出す」

ショートカット：`Ctrl+B`

ここから、マスター処理を含むWAVまたはMP3を書き出せます。

同じメニューでは、マスター処理の一括有効／無効、参照音源の波形表示と試聴もできます。

MP3書き出しには、別途FFmpegとlibmp3lameが必要です。

プロジェクト情報をWAV / MP3のタグに出力する機能もあります。

マスター画面からステムを新しいフォルダーへ書き出せますが、バスと子トラックが重複する場合があります。また、マスターの非線形FXによって、ステムを合計しても元のミックスと一致しないことがあります。

以下は未実装のため無効表示です。

- リージョン／トラックを元位置にオーディオ化する機能
- 全トラックの置き換え

ボタンが押せなくても、あなたのマウスが壊れているわけではありません。

## ちょっとした便利機能

リージョン、トラックヘッダー、ミキサーストリップを右クリックすると、背景色と文字色を変更できます。

サンプルブラウザーでは波形を表示し、Windowsの既定出力で試聴できます。

インスペクターの数値は上下ドラッグやマウスホイールで変更できます。

ASIO選択時には、設定ボタンからドライバーの設定画面を開けます。

Lua Modマネージャーでは複数の `.lua` ファイルを登録し、選択したスクリプトを明示的に実行できます。

ゲームコントローラーのボタン割り当ては、環境設定のキーコマンドから変更できます。

**F11で全画面表示を切り替えます。**

大画面にすると、それだけで少し完成度が上がった気分になれます。実装率は変わりません。

## 他社DAWのプロジェクトを食べさせる

FLP、ALS、DAWprojectなどの限定的な読み込み機能があります。

特にFLP読み込みでは、MIDIノートとその配置、参照可能な音声を取り込みます。

見つからない音声は、無音の `[Missing]` リージョンとして保持します。

該当リージョンを右クリックして「音声ファイルを再リンク…」を選び、WAVファイルを指定すると、同じ参照先を使うリージョンも更新されます。

ただし、以下の完全な再現には対応していません。

- 元の音源とエフェクト
- オートメーション
- ルーティング
- トリムやタイムストレッチ
- その他、元DAW固有の状態

**FL StudioやAbleton Liveを完全に再現できると思わないでください。**

それができたら、もはやSlop Studioではなく別の何かです。

## Slop Studio 0.13の追加機能

### マスター音量とMIDI

右上の角形スライダーとステレオ出力フェーダーは、同じマスター音量を制御します。

「ファイル → MIDIを書き出す」で標準MIDIファイルを保存できます。

ピアノロール下部のベロシティ棒はドラッグで調整でき、Undoで戻せます。

### サンプルブラウザー

ブックマークとお気に入りは、素材ファイルへの参照だけを保存します。

検索対象は表示中のフォルダーまたはお気に入りです。

素材そのものを勝手に複製してくれる魔法の機能ではありません。

### テンプレート

「ファイル → プロジェクトをテンプレートとして保存」

`.sloptemplate` ファイルを作成できます。

テンプレートや同梱サンプルは、未保存のコピーとして開きます。その後、新しい `.slopdaw` に保存してください。

音声素材の参照先は引き続き維持する必要があります。

### テーマとショートカット

環境設定から以下を変更できます。

- Undo回数
- テーマ：`.sloptheme`
- ショートカット：`.slopkeys`

テーマ変更は再起動後、共通色に反映されます。

一部の独自画面では固定色が使われています。

他社DAWの公式テーマプリセットは付属しません。

外見まで改造したい方は、遠慮なくスロップを増築してください。

### Launchpad

Launchpad X / Mini MK3のProgrammerモード向けに、明示的に選択したMIDI入出力から先頭8トラック×8シーンを操作する機能があります。

ただし、**実機での検証は完了していません。**

その他のLaunchpad機種も未検証です。

対応コードがあるからといって、あなたの机にあるLaunchpadが確実に光るとは限りません。

### 同梱プロジェクト

以下のサンプルがあります。

- **EDM Sample - Melodic House**：128 BPM
- **J-Pop - Shibuya**：150 BPM

なお、サンプルのBPM自動追従とトラックのフリーズ／解除は未実装です。

BPMが勝手に合わない場合、現在のところ人間の手が必要です。

## プラグインとプリセット

プラグイン、内蔵FX、Samplerの画面上部から、次の操作ができます。

- 設定の保存・読み込み
- コピー・貼り付け
- 画面を開いた時点との比較

プリセット形式は独自の `.sloppreset` です。

コピーした設定はアプリ終了まで保持され、同じ種類のプラグインに貼り付けられます。

外部プラグイン固有のネイティブプリセット形式との相互読み込みは実装していません。

Samplerの外部サンプルはプリセットに埋め込まれないため、参照先を維持してください。

プリセットを保存したからといって、素材まで永久保存されたと思わないこと。

## AIにスロップを操作させる：MCP

Slop Studioには、stdio MCPを利用するAI連携機能があります。

通常起動時にはMCPは停止しています。

MCPクライアントから利用する場合は、次のように起動します。

```powershell
SlopStudio.exe --mcp
```

最初は読み取り専用です。

編集操作は「ウインドウ → MCP AI連携マネージャー」からセッションごとに許可する必要があります。

ファイル操作や録音待機には追加の都度確認があります。

**重要：MCPの正式な相互運用性や包括的なセキュリティ監査は未検証です。**

AIがDAWを操作するという、いかにも現代的な機能です。

ただし、AIがスロップを操作したからといって、スロップが完成品になるわけではありません。

重要なデータを扱う前にバックアップを取ってください。

## ビルド：自分だけのスロップを作ろう

Slop Studioの技術構成は以下のとおりです。

| 項目                  | 技術                 |
| ------------------- | ------------------ |
| アプリ本体               | C# / Windows Forms |
| .NET                | .NET Framework 4.8 |
| 音声・プラグイン処理          | C++                |
| ビルドシステム             | CMake              |
| 主な対象OS              | Windows 11 x64     |
| ASIO / Ableton Link | 別プロセスのGPL補助プログラム   |

**JUCEは使用していません。**

ビルドに必要なもの：

- CMake 3.24以上
- NinjaまたはMSVC
- x64 C/C++ツールチェーン
- .NET Framework 4.8対応C#コンパイラー
- 必要なSDKとライセンスファイル

具体的なビルド・テスト手順は [docs/build-and-test.md](docs/build-and-test.md) を参照してください。

付属SDKとそのライセンスは維持してください。

既存プロジェクト、音声素材、設定、Git履歴を保護した状態で開発することを推奨します。

**ソースコードは好きに改造してください。**

UIを全部作り直しても構いません。ミキサーを魔改造しても構いません。新しい機能を100個追加しても構いません。自分のコピーを全削除して一から作り直しても構いません。

何も動かなくなっても、それはあなたのSlop Studioです。

自由には、バックアップという相棒が必要です。
